§1What the seminar covers

Test-Time Training (TTT) breaks the usual assumption that a model's weights are frozen at inference. Instead, for each test example (or short window of examples), the model runs a tiny self-supervised optimisation loop on the input itself — for example, a masked-reconstruction objective — nudging its parameters to fit that specific instance before producing the prediction.

The recent TTT-layers line (Sun et al., 2024) reframes this idea as a sequence model: the RNN's hidden state is a small neural network whose weights are updated by gradient descent at every timestep, so the "state" has essentially unlimited capacity. This connects it directly to State-Space Models and linear RNNs, which are also efficient sequence models with a rich internal state.
