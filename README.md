# anlp-study-guide

A slide-by-slide study companion for **Advanced NLP, Monsoon 2026** at IIIT Hyderabad.

Every lecture slide, tutorial page, and previous-year exam question is embedded verbatim and followed by an explanation written from first principles — designed for a student who has never seen the material before.

**Live site:** https://Arihant25.github.io/anlp-study-guide/

## What's inside

- **Lectures** — Logistics, Transformers, Tokenization, Positional Encoding, Attention, More Attention
- **Tutorials** — Mathematics for Deep Learning, Talking Matrices → Word Embeddings → BERT-family
- **PYQs** — Mid-sem 2023 (with official key comparison), Mid-sem 2024

## Sources

- Lecture slides + tutorial decks: IIIT-H Advanced NLP course, Monsoon 2026
- PYQs: [VijayrajS/iiitprevpapers](https://github.com/VijayrajS/iiitprevpapers/tree/master/Electives/BouquetAI/ANLP-Advanced%20NLP)

It's plain HTML. Open `index.html` in a browser. No build step, no dependencies.
